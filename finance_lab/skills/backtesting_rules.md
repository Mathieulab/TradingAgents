# Backtesting Rules Skill

Use when creating or reviewing backtests.

Rules:

- prevent lookahead bias,
- include fees and slippage,
- report average win and average loss,
- report expectancy and max drawdown,
- compare against benchmark,
- split development and validation periods,
- avoid optimizing on one ticker only,
- document data source and date range.

Win rate alone is never enough.
