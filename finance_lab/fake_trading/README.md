# Fake Trading

This folder is reserved for paper-trading memory and fake trader simulations.

Allowed modes:

- research,
- backtesting,
- fake trading,
- paper trading.

Not allowed:

- real broker order execution,
- automatic real order placement,
- live account mutation.

Planned fake trader profiles:

- conservative_trader,
- balanced_trader,
- aggressive_trader,
- news_reactive_trader,
- technical_trader,
- llm_consensus_trader.

Use `fake_trades.schema.json` as the target record shape.
